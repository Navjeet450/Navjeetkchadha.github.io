This is the static HTML/CSS/JavaScript version for GitHub Pages.
Upload index.html, the assets folder, and the PDF resume to the root of your
GitHub repository named YOUR-USERNAME.github.io.

The profile illustration is currently a placeholder. Add a profile image later
and update index.html/CSS if you want to display your photograph.

GitHub Pages does not run Flask/Python; this version is static and works without
an application server.
